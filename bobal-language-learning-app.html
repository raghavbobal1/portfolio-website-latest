02 / FEATURES & ENGINEERING

A mobile app connected to search and media.

IELTS vocabulary flashcards

Flashcard-based study for common English examination vocabulary, offering structured repetition as part of IELTS preparation.

Article-based vocabulary discovery

Apache Solr search functionality to find words in recent news articles and help learners explore English in context.

Speaking practice

Recording and playback integrated with a speaking-test scoring workflow for IELTS-style practice.

Mobile & data tooling

The archived project lists Android Studio, RxJava, RxAndroid, Python, Scrapy, Volley and Apache Solr as technologies used by the project.

03 / WHY IT MATTERS

End-to-end thinking.

This project brought mobile application design together with backend search, content ingestion and media workflows. It's a useful example of working beyond a single UI component and integrating different system responsibilities.
